# Inabakumori Web Wallpaper Engine

An interactive, feature-rich web wallpaper built for Wallpaper Engine featuring the music collection of **Inabakumori (稲葉曇)**.

---

## 🌟 Key Features

*   **Integrated Music Player**: Built-in player with local audio tracks and custom artwork/GIF integration.
*   **APPs Connect (Beta)**: Real-time system media integration supporting Spotify, YouTube, and browser playback.
*   **Dynamic Synced Lyrics**: Automatic LRC lyrics fetching and animated text synchronization via LRCLIB API.
*   **Audio Visualizer**: High-performance real-time canvas visualizer reactive to system audio.
*   **Smart UI & Animations**:
    *   Ping-Pong auto-scrolling marquee for long titles, albums, and artists.
    *   1.5-second smooth LERP slider transitions without audio buffering glitches.
    *   Dynamic dual-color progress track (`#ffffff` progress with `#000000` background).
    *   Sequential fade transitions for navigation control buttons.
*   **Widgets**: Time/Date display and an interactive calendar panel.
